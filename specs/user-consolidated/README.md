## System Overview

The Domos Underwriter Engine is a hybrid human-AI system that:

- **Processes deal documents** into structured data
- **Analyzes deals** against standardized criteria
- **Tracks decisions** with complete audit trails
- **Manages deal flow** through a structured pipeline

All while keeping humans in control of investment decisions.

## Key Workflow

1. **Process deal documents** into structured data
2. **Analyze deals** against stage-specific criteria
3. **Record analysis** with complete rationale
4. **Make investment decisions** at each stage gate
5. **Advance deals** through the pipeline
