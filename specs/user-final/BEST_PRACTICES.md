# Best Practices

## Purpose
This document provides guidance on best practices for using the Domos Underwriter Engine effectively, ensuring high-quality analysis and efficient workflow.

## Document Preparation

### Organizing Deal Documents
- **Create standardized folder structure** for each deal
- **Use consistent naming conventions** for all files
- **Separate documents by type** (financial, property, legal)
- **Ensure clean data formats** before processing

### Financial Document Preparation
- **Use Excel format** for all financial data
- **Include clear headers** for all columns and sections
- **Provide monthly breakdowns** when available
- **Separate operating and capital expenses**
- **Include historical data** for trend analysis

### Rent Roll Preparation
- **Ensure complete unit listing** with no omissions
- **Include occupancy status** for all units
- **Provide lease terms and expiration dates**
- **Note any non-standard lease arrangements**
- **Include tenant demographic data** if available

### Property Documentation
- **Include clear property description** with all features
- **Provide detailed unit mix breakdown**
- **Document building systems and condition**
- **Include recent capital improvements**
- **Note any deferred maintenance**

## Analysis Workflow

### General Analysis Approach
- **Follow a consistent methodology** for all deals
- **Address each criterion systematically**
- **Document all assumptions explicitly**
- **Cite specific evidence** for all conclusions
- **Quantify uncertainties** where possible

### Stage-Specific Practices

#### Initial Intake
- **Verify basic eligibility** before detailed analysis
- **Confirm document completeness** early
- **Identify any red flags** for later stages
- **Document source and reliability** of information

#### Preliminary Analysis
- **Focus on market fundamentals** first
- **Validate rent assumptions** against comparables
- **Assess expense ratios** against benchmarks
- **Identify key value drivers** early

#### Full Underwriting
- **Create multiple financial scenarios**
- **Stress test key assumptions**
- **Document sensitivity to input variables**
- **Identify all material risks**
- **Develop detailed mitigation strategies**

#### IC Review
- **Focus on clear investment thesis**
- **Highlight key differentiation factors**
- **Present balanced risk assessment**
- **Provide clear recommendation rationale**

### Quality Checklist
Before completing any stage analysis:
- [ ] All required criteria addressed explicitly
- [ ] Key assumptions validated with evidence
- [ ] Risks identified with mitigation strategies
- [ ] Financial projections verified for accuracy
- [ ] Clear recommendation with confidence level

## Audit Trail Management

### Documentation Best Practices
- **Be specific in recording decision rationale**
- **Include quantitative support** for conclusions
- **Document both supporting and contrary evidence**
- **Note confidence level** for all assessments
- **Timestamp all significant findings**

### Effective Analysis Writing
- **Use clear, concise language**
- **Organize by evaluation criteria**
- **Lead with key conclusions**
- **Support assertions with specific data**
- **Address potential counterarguments**

### Decision Documentation
- **Explicitly state recommendation**
- **Provide clear justification**
- **Link to specific stage criteria**
- **Document any dissenting viewpoints**
- **Include next steps regardless of decision**

## Team Collaboration

### Communication Practices
- **Standardize analysis terminology**
- **Document decision-making authority**
- **Establish clear handoffs between stages**
- **Create shared understanding of criteria**
- **Maintain accessible deal history**

### Review Process
- **Implement peer review for critical decisions**
- **Establish clear review criteria**
- **Document review outcomes**
- **Track common issues for process improvement**
- **Regularly calibrate decision standards**

### Knowledge Management
- **Document lessons learned** from each deal
- **Create repository of precedent analyses**
- **Develop benchmark database** for key metrics
- **Maintain library of exemplar analyses**
- **Update criteria based on performance data**

## System Usage

### Command Usage
- **Use proper command syntax** precisely
- **Verify paths before execution**
- **Check command output for errors**
- **Document any manual interventions**
- **Maintain consistent workflow sequence**

### File Management
- **Create regular backups** of processed deals
- **Maintain clean pipeline directories**
- **Archive completed deals** systematically
- **Implement version control** if available
- **Document any file structure modifications**

### Performance Optimization
- **Process deals in manageable batches**
- **Optimize document sizes** before processing
- **Close unused applications** during intensive operations
- **Schedule resource-intensive tasks** appropriately
- **Monitor system performance** regularly

## Continuous Improvement

### Process Refinement
- **Track analysis time** by stage and deal type
- **Monitor decision consistency** across analysts
- **Compare projected vs. actual performance**
- **Identify common analysis challenges**
- **Update criteria based on outcomes**

### System Enhancement
- **Document feature requests** systematically
- **Report bugs with detailed reproduction steps**
- **Suggest workflow improvements**
- **Contribute to specification refinement**
- **Share automation opportunities**
