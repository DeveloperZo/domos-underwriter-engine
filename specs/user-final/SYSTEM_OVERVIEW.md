# System Overview

## Purpose
This document explains what the Domos Underwriter Engine is, what it does, and its key capabilities for LIHTC preservation investment analysis.

## What Is the Domos Underwriter Engine?

The Domos Underwriter Engine is a specialized tool for analyzing LIHTC (Low-Income Housing Tax Credit) preservation investment opportunities. It bridges the gap between institutional-grade analysis and competitive acquisition timelines.

## Key Capabilities

### Document Processing
- Extracts structured data from due diligence documents
- Parses rent rolls and financial statements
- Creates standardized JSON representations of deals
- Organizes information for consistent analysis

### Analysis Framework
- Implements a nine-stage investment evaluation process
- Applies standardized criteria at each stage
- Provides transparent decision-making logic
- Identifies edge cases requiring special attention

### Audit and Transparency
- Creates a complete audit trail of all analysis
- Records timestamps for all decisions
- Documents reasoning behind each recommendation
- Maintains full history for compliance purposes

### Deal Pipeline
- Tracks deals through defined workflow stages
- Manages state transitions based on analysis
- Provides visibility into deal status
- Supports a structured decision process

## System Architecture

The system consists of these core components:

1. **Processing Engine**: Converts documents to structured data
2. **Analysis Pipeline**: Manages the nine-stage evaluation process
3. **Transparency Layer**: Records all decisions with explanations
4. **Command Interface**: Provides tools for interaction with the system

## When to Use This System

The Domos Underwriter Engine is designed for:

- LIHTC preservation investment analysis
- Affordable housing acquisition evaluation
- Standardized underwriting of preservation opportunities
- Creating audit-ready investment decision trails

## Core Principles

The system operates according to these principles:

1. **Transparency**: All decisions are explained and documented
2. **Consistency**: Standardized criteria applied to all deals
3. **Efficiency**: Streamlined processes for faster analysis
4. **Rigor**: Institutional-grade analysis standards
5. **Human Control**: System supports but doesn't replace human judgment
